`scripts/export_readable_csv.py`의 출력 및 기존 CSV 백업 입력 경로를 `reports/receipts/`로 변경했습니다. 백업 저장 위치 `dataset/ocr_original_exports/`는 유지합니다. CSV는 재생성하지 않았으며 이동 전후 SHA-256이 동일함을 확인했습니다.

`check.md`는 라벨과 사용자 수정 기록의 출처로 참조되므로 루트에 유지합니다. `AGENTS.md`, `README.md`, `requirements.txt`도 프로젝트 루트에 유지합니다.

`dataset/`, `receipt/`, Hugging Face 캐시, `ocr_baseline/`, `training/`, 가상환경은 코드 및 설정에서 현재 경로를 참조하므로 그대로 유지합니다. 학습 로그와 체크포인트도 이동하거나 삭제하지 않았습니다. 기존 Git 스테이징 상태는 변경하지 않았습니다.

문서의 실행 명령은 별도 안내가 없으면 프로젝트 루트에서 실행합니다. 이번 작업은 파일 배치와 참조 경로 정리이며, 데이터 변환·패키지 설치·학습·평가를 실행하지 않았습니다. 기존 문서의 실험 결과와 학습 상태는 이번 작업에서 새로 검증한 결과가 아닙니다.
