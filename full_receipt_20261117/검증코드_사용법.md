# 평가계획 사전 검증

`verify_plan.ps1`은 Windows PowerShell 5.1에서 설치 없이 실행하는 읽기 전용 검사기다. 원본이나 기존 결과는 수정하지 않으며 실행마다 별도 폴더를 만든다. 다운로드·압축 해제·학습·OCR 추론은 하지 않는다.

## 확인한 PC 상태 (2026-11-17)

- NVIDIA-SMI: RTX **5070 Ti**, 16303 MiB, 드라이버 616.56. 기존 문서의 5060 Ti와 다르다.
- CUDA UMD 13.4 표시는 Toolkit 버전이 아니다.
- `py -0p`에는 Python이 등록되지 않았다. `python3.12.exe`는 발견되지만 실행 시 애플리케이션 제어 정책에 의해 차단됐다. 정책을 변경하지 않았다.
- WSL 배포판 실행 환경은 준비되지 않은 상태로 보고됐다. Docker 명령도 발견되지 않았다.
- `training/exports/selected`의 추론 모델 3개 파일은 존재한다. baseline/검출 모델 경로는 별도로 지정해야 한다.
- 프로젝트 `dataset/manifest.json`의 출처는 HumynLabs/Korean_Receipts_Dataset이다. 이를 KORIE로 간주하지 않는다.

## 실행

프로젝트 루트에서 PowerShell로 실행한다.

현재 PC 기본 실행 정책은 PS1 실행을 차단한다. 로컬에서 검토한 이 스크립트만 실행하려면 아래 명령의 `-NoProfile` 뒤에 `-ExecutionPolicy Bypass`를 추가할 수 있다. 이는 해당 프로세스에만 적용하며 영구 정책은 변경하지 않는다. 실제 검증도 이 방식으로 수행했다.

```powershell
Set-Location D:\ssafy\ocr\mogumogu
powershell -NoProfile -File .\full_receipt_20261117\verify_plan.ps1
```

다운로드가 끝난 뒤에는 실제 경로를 지정한다. 아래 변수는 사용자가 확인한 경로/출처를 입력받으므로 가상 경로를 실제 파일처럼 사용하지 않는다.

```powershell
$data = Read-Host '압축 해제된 공식 KORIE 폴더 절대 경로'
$zip = Read-Host '보관한 원본 ZIP 절대 경로'
$url = Read-Host '공식 다운로드 URL'
$revision = Read-Host '출처 commit 또는 확인 날짜'
powershell -NoProfile -File .\full_receipt_20261117\verify_plan.ps1 -DataRoot $data -Archive $zip -SourceUrl $url -SourceRevision $revision
```

`-BaselineDir`, `-DetectorDir`에는 확인한 로컬 Paddle 추론 모델 디렉터리를 전달한다. 검사기는 JSON/PDPARAMS/YML 내보내기 파일을 확인한다. 다른 형식의 검출기는 별도 확인이 필요하다.

출력은 `full_receipt_20261117/verification/<시각_UUID>/`의 `report.json`, 선택 입력에 따라 `zip_inventory.csv`, `data_inventory.csv`다. 종료 코드 1은 파일 검사 실패, 2는 아직 확인할 항목이 남았다는 뜻이다. 현재 버전은 전체 OCR 준비 완료를 선언하지 않는다.

검사 범위: GPU/명령 위치/디스크 여유 공간, 모델 SHA-256, ZIP 크기·해시·내부 목록·위험 경로, 이미지 로딩 및 크기, JSON/JSONL 문법, 확장자별 수량. ZIP은 추출하지 않고 내부 CRC까지 검증하지 않는다. 이미지 로딩 검사는 픽셀 전체의 무결성을 보장하지 않는다. TXT 라벨은 형식 미확인으로 문법 검사를 하지 않는다.

## 남은 구현 경계

공식 원본 annotation을 실제 확보하여 스키마를 확인한 뒤 split/원본–crop ID 연결, 좌표 범위, 문자 사전/길이 검사 어댑터를 추가해야 한다. 현재 코드는 이를 모두 `NEEDS_CONFIRMATION`으로 기록한다. JSON 문법 통과를 라벨 의미 검증으로 오인하지 않는다.

고정 검출 결과 생성, 두 인식 모델 실행, IoU 대응, CER/Exact Match/금액 평가, 시각화는 이 사전 검증기의 범위에 포함되지 않는다. 아직 정답 범위와 단위가 확인되지 않아 임의 채점기를 만들지 않았다. 원본 계획의 최종 평가 파이프라인은 미완성 상태다.

## 검증 기록

실제 PC에서 입력 데이터 없이 실행하여 GPU/모델 파일 확인과 JSON 보고서 생성을 검증했다. 공식 ZIP/전체 영수증 입력 검사는 데이터 미확보로 실행하지 않았다. 패키지 설치, 다운로드, 변환 및 학습은 수행하지 않았다.
